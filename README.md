# 충남·천안 교육기관 위치정보

인사이동 예상도에서 사용하는 **공개 기관 위치 목록**입니다. 직원 이름, 발령자료, 재직기간, 개인 메모, API 키는 포함하지 않습니다.

## 파일

- `institutions.json`: 기관 고유번호, 기관명, 유형, 상위 기관, 지역, 주소, 위도·경도, 별칭, 출처, 기준일, 직접 확인 여부.
- `validate.mjs`: 허용 필드와 좌표 범위를 검사합니다. `node validate.mjs`로 실행합니다.
- `search-missing.mjs`: 좌표가 없는 기관에 대해서만 카카오 검색 후보를 만듭니다. 검색 결과를 검토한 뒤 반영합니다.
- `pending-institutions.example.json`: 좌표 보완 요청 입력 예시입니다. 직원 정보는 적지 않습니다.

## 갱신 순서

1. 비공개 웹앱의 **위치정보**에서 기관을 찾습니다. 이름만 다르면 기존 기관에 별칭을 추가합니다.
2. 목록에 없는 기관은 주소 또는 지도 위치로 추가합니다. 카카오 검색은 API가 연결된 경우 사용할 수 있습니다.
3. 검색 후보가 실제 기관인지 지도와 주소로 확인한 후 저장합니다.
4. **GitHub용 목록 저장**으로 `institutions.json`을 내려받고 이 저장소의 같은 파일을 교체합니다.
5. `node validate.mjs`를 실행해 확인합니다. 웹앱을 다시 열면 이 저장소의 목록을 읽습니다. 직접 보정한 기기 내 위치를 우선 사용합니다.

## 누락된 기관만 API로 검색

`pending-institutions.example.json`을 참고해 `pending-institutions.json`을 만듭니다. 환경변수 `KAKAO_REST_API_KEY`를 설정하고 `node search-missing.mjs`를 실행합니다. 이미 좌표가 있는 항목은 호출하지 않습니다. 기관명보다 정확한 도로명주소가 있으면 주소 검색을 우선 사용합니다.

결과는 `location-candidates.json`에 저장됩니다. 좌표를 자동 확정하거나 GitHub에 자동 업로드하지 않습니다. 같은 이름의 다른 기관, 이전·폐교, 본청·지역청의 같은 부서명을 확인한 뒤 반영합니다. 카카오 API 이용 조건과 호출 한도를 따릅니다.

## 원자료

- 사용자가 제공한 전국초중등학교위치표준데이터 CSV의 충청남도 학교.
- 충청남도교육청 천안특수교육지원센터 관내기관정보(2025-09-01)의 단설유치원·특수학교 등.
- 천안교육지원청 대표 좌표는 기존 분석기 값으로, 직접 확인 전까지 `verified: false`로 표시합니다.

원자료별 기준일과 출처를 각 항목에 기록합니다. 자료 이용 조건은 각 제공기관의 조건을 따르며, 이 저장소가 별도 이용권을 부여하지 않습니다. 학교 목록 전체가 지방공무원 배치 대상임을 뜻하지는 않습니다.

## 구분 원칙

- `충청남도교육청/재무과`와 `천안교육지원청/재무과`는 다른 기관입니다.
- 약칭은 `aliases`로 연결합니다. 동명 기관을 임의로 합치지 않습니다.
- `verified`는 직접 위치를 확인했는지 나타내며 인사자료의 정확도를 의미하지 않습니다.
- 인사 웹앱은 별도 비공개 사이트입니다. 공개 위치정보 저장소에는 인사자료를 올리지 않습니다.
